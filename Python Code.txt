Q-26: Calculate Speed Fine


s=int(input("Enter (KM/H)"))
if(s<=60):
    fine=0
elif(s<=80):
    fine=(s-60)*500
elif(s<=100):
    fine=(20*500)+(s-80)*1000
elif(s>=100):
    fine=(20*500)+(20*1000)+(s-100)*2000
else:
    fine=0
print("Fine per KM/H",fine)


Output:
Enter (KM/H) :75
Fine per KM/H 7500

elif(u<=300):
    bill=(100*2)+(100*3)+(u-200)*5
elif(u<=300):
    bill=(100*2)+(100*3)+(100*5)+(u-300)*7
else:
